Questions to your own documents – answered with sources

LocaNoto is a local AI knowledge base for companies. It searches documents, mailboxes, calendars, databases and Excel lists and names file and page for every answer. Everything runs in your own network with local language models – the data never leaves it.

Features

Answers with sources

PDF, Word, Markdown, text and scanned pages. Every statement with file and page; one click opens the passage.

Workspaces and permissions

Shared workspaces per department, a private one per user, sign-in through the company directory (OIDC).

Mailbox and calendar

Exchange and IMAP: read and summarise mail; replies, appointments and invitations as drafts – nothing is sent before a person confirms.

Database and lists

Questions to the ERP (Microsoft SQL Server, read-only, with each user's own rights) and to Excel lists on a network drive.

Ticket system

Shared mailboxes like info@ become tickets: a standard answer with the number, assignees, status and history.

Web search on confirmation

The model proposes a search; only the search text the user confirms goes out. Hits can be taken over as sources.

Create files

Excel, Word, PDF and PowerPoint from an answer, stored in the user's own workspace on request.

Runs on your premises

Docker or Kubernetes, Postgres with pgvector, encrypted storage, OpenCloud/Nextcloud, HTTP API.

Installation

Requirements: Python 3.8 or newer, Docker or kubectl and an OpenAI-compatible model server (e.g. vLLM, Ollama, LiteLLM). The installer creates keys and certificates, starts every service, creates the first admin account and checks every part at the end.

Project

LocaNoto is developed in the project DIG:IT-KMU at the Institute for Digital Engineering (IDEE) of the Technical University of Applied Sciences Würzburg-Schweinfurt (THWS). The aim is AI that small and medium-sized companies can use with their own data and without a cloud. Funded under EFRE Bavaria 2021–2027 by the Bavarian State Ministry of Economic Affairs, Regional Development and Energy, co-financed by the European Union.
